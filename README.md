# Descripción del Proyecto 2: 🏥 MediFlow

MediFlow; Debe resolver desafíos complejos de visión multimodal, extracción estructurada de datos clínicos,
lógica de decisión condicional y manejo de casos ambiguos o urgentes (como datos ilegibles,
prescripciones de alto riesgo o solicitudes de urgencia).

El objetivo del proyecto es diseñar, construir e implementar un agente de inteligencia artificial autónomo, especializado en la automatización del flujo de trabajo documental para entornos de salud.

# Etapas del proyecto:

- Módulo de Recepción y Procesamiento MultiFormato:

  El sistema procesará activamente archivos PDF digitalizados estructurados y no estructurados,
  imágenes de alta y baja resolución (como recetas médicas manuscritas,
  órdenes de laboratorio y estudios diagnósticos) y bloques de texto plano o notas clínicas digitalizadas.
  
- Motor de Clasificación Automatizada de Documentos:

  El sistema discriminará con total autonomía si el documento corresponde a un historial clínico,
  una receta médica, una factura administrativa, un resultado de laboratorio o un informe de seguros.
  
- Componente de Extracción de Entidades y Datos Clínicos de Alta Precisión:

  Mediante el uso de modelos de Procesamiento de Lenguaje Natural especializados en el dominio médico,
  el agente identificará, aislará y extraerá con un nivel crítico con mínimo margen de error las variables esenciales.
  Esto incluye datos del paciente tales como nombre, diagnósticos, medicamentos, dosis, fechas clave,
   así como los datos del medicos por mencionar algunos nombre, matricula de cédula profesional, horario de trabajo.

- Flujo de Enrutamiento Inteligente y Asignación Automático de los expedientes clinicos:

  El agente validará la información y redirigirá de forma automatizada los documentos y sus metadatos hacia el sistema de destino correspondiente,
  
  
- Desplegar en OCCI:

  Proyecto desplegado en los servidores de oracle alwaysfree para demostración y uso del proyecto publicamente.
